**Тема:** Використання SFML в C++ проєкті. Використання пакетного менеджера vcpkg  
**Завдання (Варіант 28):** Рух частинки під дією гравітації та вітру  
**Виконала:** Студентка групи ФІТ 3-10 Черниш Ірина Віталіївна  

## Опис проєкту
Інтерактивна графічна програма мовою C++17 із використанням бібліотеки **SFML 3.1.0**, системи збірки **CMake** та пакетного менеджера **vcpkg** у режимі маніфесту (`vcpkg.json`). Програма моделює рух частинки у двовимірному просторі під дією вертикального прискорення вільного падіння та горизонтального прискорення вітру, відображає траєкторію польоту, індикатор сили вітру та поточні фізичні параметри.

## Керування в програмі
* **`←` / `→` (Стрілки вліво / вправо):** зміна сили та напрямку вітру (зустрічний / попутний)
* **`↑` / `↓` (Стрілки вгору / вниз):** зміна початкової швидкості запуску частинки
* **`Space` (Пробіл):** запуск або пауза моделювання
* **`R`:** перезапуск моделювання з поточними параметрами

## Структура проєкту
* `main.cpp` — вихідний код фізичної моделі та графічного інтерфейсу SFML
* `CMakeLists.txt` — конфігурація збірки проєкту CMake
* `CMakePresets.json` — налаштування пресетів збірки з інтеграцією vcpkg
* `vcpkg.json` — маніфест залежностей проєкту (`sfml`)
* `resources/fonts/arial.ttf` — шрифт для відображення текстової інформації у вікні

## Збірка та запуск
```powershell
cmake --preset default
cmake --build --preset default
.\build\Debug\SFML_Lab.exe
```
